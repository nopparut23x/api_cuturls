# URL Shortener API

This is a simple URL shortening service built with Node.js, Express, and PostgreSQL using Knex.js. It allows you to shorten URLs and retrieve the original URL by using the short link.

## Features
- Shorten a given URL
- Retrieve the original URL from a shortened URL
- Database integration using PostgreSQL (via Knex.js)
- CORS support for cross-origin requests
- Error handling and validation for URL shortening
